# 从函数到分析 · 数学进阶之路

一条从高中数学通往微积分、再通往严格数学分析的完整进阶之路。课程结构参考普林斯顿大学数学系本科培养体系（MAT 100 → 103 → 104 → 201 → 215 → Stein 分析四部曲），全程以交互式图像为舟，以练习与讲解为桨。

纯原生 JavaScript 单页应用，**零依赖、零构建**——克隆后用任意静态服务器打开 `index.html` 即可运行。

## 快速开始

```bash
# 任选一种方式启动本地服务
python3 -m http.server 8765
# 或 npx serve .

# 浏览器打开 http://localhost:8765/
```

> 直接双击 `index.html`（file:// 协议）亦可运行；使用本地服务器体验更佳。

## 课程结构

| 学部 | 对应课程 | 章节 | 练习 |
|------|----------|------|------|
| I 筑基 · 高中数学核心 | MAT 100 预备微积分 | 3 | 12 |
| II 微积分 · 极限与变化 | MAT 103 / 104 / 201 | 7 | 28 |
| III 数学分析 · 严格性革命 | MAT 215 荣誉分析（Rudin） | 6 | 24 |
| IV 分析四部曲 | Stein & Shakarchi I–IV | 4 | 16 |

参考教材：Walter Rudin《数学分析原理》、Stein & Shakarchi《普林斯顿分析讲义》。

## 功能特性

- **22 个交互式图形化教学组件**：ε-δ 极限实验室、黎曼和可视化、Darboux 上下和、紧致性开覆盖、傅里叶吉布斯现象、康托集测度……全部 Canvas 手绘，滑块/拖拽实时联动
- **自研 MiniTeX 公式渲染器**：约 200 个 LaTeX 命令子集，无需引入 KaTeX/MathJax
- **80 道配套练习**：每题附 Step 1/2/3 分步讲解、几何直觉与易错点提示
- **移动端适配**：窄屏下侧栏抽屉化（带遮罩/滚动锁定）、画布高度自适应、控件单列堆叠、粗指针滑块放大，`touch-action` 消除触控延迟
- **错题本**：答错自动收录，就地重做直至攻克，三档筛选 + 学部分组
- **进度持久化**：localStorage 记录答题与浏览历史，首页总览各学部进度

## 技术说明

- 无框架、无构建工具、无外部 CDN 依赖，所有渲染与交互均为原生实现
- 路由采用 hash 模式（`#/ch/:div/:chapter`、`#/wrongbook`）
- 用户数据仅存于浏览器 localStorage（键前缀 `mp-progress`），无任何后端
